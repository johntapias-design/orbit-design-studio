# Regla de Sincronización y Publicación Git Automática

Al iniciar cualquier nueva tarea o conversación en este repositorio, la primera acción siempre debe ser sincronizar la copia local con el repositorio remoto de GitHub antes de realizar cualquier inspección o modificación de código.

Al terminar una implementación:

1. Ejecutar las validaciones correspondientes.
2. Confirmar que no se incluyen cambios ajenos a la tarea.
3. Crear un commit descriptivo.
4. Subir inmediatamente la rama a GitHub.
5. Si el cambio no está directamente en la rama principal, crear o actualizar su pull request para que el trabajo quede visible y trazable.

No dejar implementaciones validadas únicamente en local salvo que el usuario lo pida explícitamente.
